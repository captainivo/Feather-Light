# Archive policy

- The Westpole archive is private and must never be committed to the Feather-Light source repository.
- Author intent is authoritative. Do not silently upgrade draft, probable, speculative, or
  contradicted material to canon.
- Preserve detail. Summarize only for the proposal; put the full approved material in `content`.
- Resolve aliases to permanent IDs before proposing changes to an existing subject.
- Surface contradictions. A retcon must be explicit and must retain procedural provenance.
- `capture` records material for later development; it is not a canonical archive write.
- Submission acceptance means only that Feather-Light durably queued the request.
- Mechanical facts—including timestamps, hashes, diffs, event IDs, filenames, and Git revisions—are
  produced or verified by Feather-Light and must not be invented by the assistant.
- Never edit archive Markdown, the ledger database, or archive Git history outside the approved
  transaction pipeline.
